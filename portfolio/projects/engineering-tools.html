设备样品测试自动化

针对人工重复配网、控制和 OTA 测试的工作，调研并落地基于 USB 通信的 iOS 样品测试方案。通过 PeerTalk 等能力连接手机与电脑，使测试流程能够接受指令并重复执行，减少依赖人工逐次操作。

把包体积检查放进 CI

开发 Python CI Trigger，围绕 LinkMap、图片去重与压缩、模块和静态库大小检查生成报告和阈值提醒。工具的价值是把易遗漏的问题提前到构建阶段，让团队能根据具体结果处理。

AI 时代延续同一个原则

在近期项目中，Claude Code、Codex 承担大量代码实现。我把更多精力用于拆解任务、核对协议、检查实际产物以及验证边界条件。效率应以完整交付衡量，生成代码只是其中一步。

Engineering tools for repetitive work

Earlier tooling work included a USB-connected device test platform and CI package-size checks. The same principle now shapes my AI-assisted development practice: automate implementation while retaining validation and engineering ownership.
